# 03 — Tecnologías

## Stack elegido
- Frontend: React + TypeScript + Vite + Tailwind CSS (mobile-first)
- Backend/BaaS: Firebase Auth + Firestore
- Routing: React Router DOM
- Lint: oxlint
- Tests: vitest (tests automatizados)
- Despliegue: Vercel/Netlify (se justificará URL pública)

## Justificación (TP N° 2)
Se mantiene el stack por familiaridad, rapidez, seguridad con reglas por rol y adecuada para el alcance.

## Cambio con respecto a "clase"
Si bien se trabajó con React, el stack se mantiene. Se agregan tests automatizados (vitest) y variables CSS de diseño.
