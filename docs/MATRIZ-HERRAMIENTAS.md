# Anexo I: Matriz de selección de herramientas de IA

| Tarea | Herramienta seleccionada | Justificación | Uso (sí/no/parcial) |
|------|---------------------------|---------------|---------------------|
| Editor con agente | opencode (CLI) | Integrado al entorno, permite skills, comandos personalizados, seguimiento de tareas. | Sí |
| Especificación / SDD | opencode | Genera y mantiene spec/clarificacion/plan/tasks/verificacion siguiendo el ciclo. | Sí |
| Código / refactor | opencode | Revisión humana obligatoria, cambios por tarea. | Sí |
| Debugging / corrección | opencode | Análisis y corrección con explicación. | Sí |
| Imágenes IA | A definir (ChatGPT/GPT Image, Ideogram, Midjourney, Flux, Bing) | Buscar fotorrealismo, coherencia con marca, Tinogasta. Revisar condiciones de uso. | Pendiente |
| Video promocional IA | A definir (Kling, PixAI, Hunyuan Video, Pika, Canva) | Generar clips, editar con subtítulos/música. | Pendiente |
| Voz / locución | A definir | Solo si necesario, respetando consentimiento. | Pendiente |
| Gráficos / infografía | A definir (Canva/Bing/Codex) | Generar con datos reales del proyecto. | Pendiente |
| Documentación / informe | opencode + revisión humana | Redacción asistida, siempre revisada. | Sí |

## Editor con agente elegido
- Editor: opencode
- Razón: Permite trabajar con skills, comandos, memoria, revisión paso a paso y documentación del proceso.
