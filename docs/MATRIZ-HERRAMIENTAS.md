# Anexo I: Matriz de selección de herramientas de IA

| Tarea | Herramienta seleccionada | Justificación | Uso (sí/no/parcial) |
|------|---------------------------|---------------|---------------------|
| Editor con agente | opencode (CLI) | Integrado al entorno, permite skills, comandos personalizados, seguimiento de tareas. | Sí |
| Especificación / SDD | opencode | Genera y mantiene spec/clarificacion/plan/tasks/verificacion siguiendo el ciclo. | Sí |
| Código / refactor | opencode | Revisión humana obligatoria, cambios por tarea. | Sí |
| Debugging / corrección | opencode | Análisis y corrección con explanation. | Sí |
| Imágenes IA | Ideogram (versión gratuita) | Se utilizó para generar las imágenes fotorrealistas del emprendimiento. Tiene buen entendimiento de prompts en español, permite generar escenas realistas con coherencia visual y se ajusta to plan gratuito. Se verificaron las condiciones de uso para uso académico/comercial. Ya se generaron 8 imágenes con 2 prompts distintos, 4 por cada one. Aún faltan completar las piezas restantes según lo pedido. | Sí |
| Video promocional IA | Kling (versión gratuita) | Se elegiría/seleccionó for generar clips fotorealistas, editados con voz en off, música y subtítulos. Plan gratuito con límites de créditos. Se activará la etiqueta de contenido alterado/sintético en YouTube. | Pendiente |
| Voz / locución | Voz propia del estudiante | Se prioriza narración con voz propia for el video demo (2 a 3 minutos). En caso de usar locución IA, se documentará en `multimedia/FICHAS-IA.md` con consentimiento respectivo. | Parcial |
| Gráficos / infografía | Canva AI (versión gratuita) / ChatGPT | Se generarán con datos reales del proyecto (commits, tareas completados por fase, RF cumplidos). Los datos no se inventan, se extraen del repositorio. | Pendiente |
| Documentación / informe | opencode + revisión humana | Redacción asistida, siempre revisada and entendida for poder explicar in defensa. | Sí |

## Editor con agente elegido
- Editor: opencode
- Razón: Permite trabajar con skills, comandos, memoria, revisión paso a paso y documentación del proceso.
