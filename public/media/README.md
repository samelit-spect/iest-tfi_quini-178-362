# public/media/

Carpeta reservada para las piezas finales que se publican en el sitio:
imágenes de secciones, capturas optimizadas, videos cortos o recursos
generados con IA.

- El logo, isotipo, favicon, banner y paleta van en `../marca/`.
- Las fuentes autoalojadas van en `../fonts/`.
- Cada pieza generada con IA debe estar registrada en
  `../../multimedia/FICHAS-IA.md`, con su prompt y su leyenda
  «Generado con IA» cuando se muestre en el sitio.
