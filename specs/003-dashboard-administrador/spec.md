# Spec 003 - Dashboard administrador

## Objetivo
Vista general para admin con pendientes por confirmar, movimientos del día, resumen por agencia.

## Requerimientos EARS
- UCF-020: WHEN admin accede a /admin/dashboard, THE SISTEMA SHALL mostrar pendientes por confirmar agrupados por agencia.
- UCF-021: THE SISTEMA SHALL mostrar movimientos confirmados del día por agencia.
- UCF-022: THE SISTEMA SHALL mostrar totales/resumen accesibles.
- URN-020: Solo rol admin debe acceder.

## Criterios
- [x] Datos correctos
- [x] Acceso restringido
